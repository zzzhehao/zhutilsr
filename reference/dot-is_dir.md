# Check if paths exists and are directories.

Check if paths exists and are directories.

## Usage

``` r
.is_dir(path, error = F)
```

## Arguments

- path:

  Character vector. Path(s) to be tested.

- error:

  Logical. Whether throw an error if any path didn't pass the text.
  Default to `FALSE`.

## Value

A logical vector in same length of `path`.
