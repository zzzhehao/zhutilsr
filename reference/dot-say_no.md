# Gracefully say no

Powered by hotheadhacker/no-as-a-service
(https://github.com/hotheadhacker/no-as-a-service).

## Usage

``` r
.say_no(verbose = cat)
```

## Arguments

- verbose:

  A function to say no. Default to `cat`. Set to `NULL` to silently
  return no without saying it out loud.

## Value

A variety of ways to say no.
